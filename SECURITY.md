# Security Policy

The Frappe team and community take security issues in Frappe Charts seriously. To report a security issue, please email [security@frappe.io](mailto:security@frappe.io). Please do not report security issues through public GitHub issues, pull requests or the forum.

Before you report, please read our [security policy](https://frappe.io/security). It covers scope, what to include in a report, disclosure, CVE assignment and credits.

## Supported Versions

We provide security fixes only for the latest release of Frappe Charts. Fixes are not backported to older releases.

To get security fixes, update the package to the latest version with your package manager, for example `npm install frappe-charts@latest`. If you find a vulnerability in an older release, please check that it still exists in the latest release before you report it.

## Security Advisories

We publish security advisories for Frappe Framework in this repository's [Security tab](https://github.com/frappe/charts/security/advisories).
